# FRESH STOCK — Академия склада

Полный стартовый проект Streamlit + Supabase + ежедневный GitHub Actions sync.

## Что реализовано
- Вход менеджеров и руководителя (самостоятельной регистрации нет).
- Каталог автомобилей с фотографиями из публичных объявлений (если фото присутствует в HTML карточки), ценами, характеристиками и ссылкой на источник.
- Фильтры по топливу, коробке, приводу и бюджету.
- Флеш-карточки, викторина, угадывание цены, подбор под запрос, сравнение, экзамен.
- Запись тренировочных событий и баллов в Supabase.
- Кабинет руководителя со списком сотрудников и результатами.
- Ежедневный запуск синхронизации GitHub Actions в 08:00 по Краснодару (UTC+3).

## Важные ограничения до запуска
1. Сборщик использует публичную HTML-разметку и может потребовать адаптации, если сайт Fresh меняет DOM или загружает карточки динамически. Он не обходит CAPTCHA/антибот.
2. URL склада должен оставаться именно тем фильтром Fresh Краснодар Дзержинского, который вы подтвердили. Проверьте филиал в выдаче перед запуском синхронизации.
3. На текущем этапе парсер извлекает поля best-effort. Не найденные характеристики остаются пустыми, не угадываются.
4. Фотографии отображаются по исходному URL объявления; они не скачиваются и не копируются. Доступность зависит от правил и hotlink-защиты Fresh. Для постоянного хранения нужно согласовать право локального копирования с владельцем сайта.
5. Удаление/продажа авто автоматически не выполняется: отсутствующие в одном запуске записи не удаляются, чтобы временная ошибка не очистила каталог. Нужна отдельная политика подтверждения по нескольким успешным синхронизациям.
6. Этот комплект — код проекта, не развернутый сервис. Нужны действия владельца GitHub/Supabase/Streamlit и проверка фактической работы парсера.

## 1. Создайте базу Supabase
- Создайте проект на https://supabase.com/
- Откройте SQL Editor, выполните содержимое `schema.sql`.
- Скопируйте Project URL и service_role key из Project Settings → API.
- Service role key — секрет администратора. Не публикуйте его и не добавляйте в GitHub.

## 2. Добавьте секреты в Streamlit
В Streamlit Community Cloud → приложение → Settings → Secrets добавьте:
```toml
SUPABASE_URL = "https://YOUR-PROJECT.supabase.co"
SUPABASE_KEY = "YOUR_SUPABASE_SERVICE_ROLE_KEY"
```
В production лучше использовать отдельный backend/API и политики доступа; этот прототип обращается к Supabase из серверного кода Streamlit. Не вставляйте секрет в исходники.

## 3. Создайте первого руководителя
Сгенерируйте SHA-256 хеш пароля локально:
```bash
python -c "import hashlib; print(hashlib.sha256('YOUR_LONG_UNIQUE_PASSWORD'.encode()).hexdigest())"
```
В Supabase SQL Editor:
```sql
insert into employees(username,full_name,password_hash,role)
values ('admin','Руководитель','ВСТАВЬТЕ_ХЕШ','admin');
```
Затем добавьте менеджеров аналогично с role='manager'. Не отправляйте пароли в чат.

## 4. Загрузите файлы в GitHub
Замените старые `app.py` и `requirements.txt`, добавьте:
- `sync_inventory.py`
- `schema.sql`
- `.github/workflows/daily-sync.yml`
- `.gitignore`

Commit в ветку `main`.

## 5. Секреты GitHub Actions
GitHub repo → Settings → Secrets and variables → Actions → New repository secret:
- `SUPABASE_URL` = Project URL
- `SUPABASE_SERVICE_ROLE_KEY` = service_role key
- `FRESH_STOCK_URL` = точный URL фильтра Fresh Краснодар Дзержинского

Вкладка Actions → Daily Fresh stock sync → Run workflow для первой ручной синхронизации.
Дальше запуск ежедневно в 05:00 UTC = 08:00 Краснодар.

## 6. Разместите приложение
В https://share.streamlit.io/:
- Repository: `messtizo/fresh-stock`
- Branch: `main`
- Main file: `app.py`
- Deploy

Streamlit Community Cloud → App settings → Secrets: добавьте секреты из шага 2.

## 7. Проверка перед реальным использованием
- Проверьте, что каталог содержит только автомобили требуемого филиала.
- Сверьте 10–15 карточек с сайтом: цена, пробег, двигатель, КПП, привод, мощность.
- Убедитесь, что изображения отображаются и ссылка ведёт на соответствующее объявление.
- Создайте тестового менеджера и проверьте вход с другого устройства.
- Проверьте запись баллов и просмотр кабинета руководителя.
- Проверьте лог Actions после первой синхронизации.

## Безопасность
Этот стартовый комплект рассчитан на пилот. Перед рабочим использованием отдела продаж желательно:
- заменить SHA-256 на bcrypt/argon2 и добавить ограничение попыток входа;
- включить Row Level Security и безопасный серверный API; не давать менеджерам service_role;
- сделать приглашение/сброс пароля администратором;
- внедрить журнал цен и подтверждение снятия авто после 2–3 успешных полных синхронизаций;
- проверить условия использования сайта и разрешение на автоматический сбор/использование изображений.
