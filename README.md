# FRESH STOCK — Академия склада

Прототип на Streamlit.

## Запуск локально
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Размещение на Streamlit Community Cloud
- Repository: `messtizo/fresh-stock`
- Branch: `main`
- Main file path: `app.py`

## Важно
Встроенный набор из 6 автомобилей — демонстрационные данные, а не полный актуальный склад.
Прогресс пока хранится только в текущей сессии. До рабочего запуска нужно подключить постоянную БД,
реальную синхронизацию публичного каталога, фотографии, роли сотрудников и отдельный планировщик
ежедневного обновления. Не храните пароли или токены в исходном коде.
